# Bioinformatics Report — Porphyria Cutanea Tarda Type 2 (PCT)
**Course:** Introduction to Bioinformatics · UPC · 2026–2027
**Group:** Porphyria Cutanea Tarda Type 2 (PCT)
**Authors:** Sara Charif Karkri el Abbassi and Laia Núñez Palma

## Description
This study provides a comparative bioinformatic, sequence alignment, and 3D structural analysis of uroporphyrinogen decarboxylase (UROD) to elucidate the molecular pathomechanism of porphyria cutanea tarda type 2 (PCT2). By evaluating the human wild-type and disease-associated variant (c.779T>C,p.Ile260Thr) alongside evolutionary orthologs (Pan troglodytes and Bacillus subtilis), we propose that pathogenicity may be driven by local physicochemical disruption close to the active site rather than large-scale global structural distortion.
