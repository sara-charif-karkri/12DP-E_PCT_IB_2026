# Bioinformatics Report — Porphyria Cutanea Tarda Type 2 (PCT)
**Course:** Introduction to Bioinformatics · UPC · 2026–2027  
**Group:** Porphyria Cutanea Tarda Type 2 (PCT)  
**Authors:** Sara Charif Karkri el Abbassi and Laia Núñez Palma  

## Description
This study provides a comparative bioinformatic, sequence alignment, and 3D structural analysis of uroporphyrinogen decarboxylase (*UROD*) to elucidate the molecular pathomechanism of Porphyria Cutanea Tarda Type 2 (PCT2). By evaluating human wild-type and disease-associated mutant variants (c.779C>T, p.Ile260Thr) alongside evolutionary orthologs (*Pan troglodytes* and *Bacillus subtilis*), we demonstrate that pathogenicity is driven by local physicochemical disruption within the buried hydrophobic core rather than large-scale global structural distortion.
