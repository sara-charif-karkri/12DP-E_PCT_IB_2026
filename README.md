# Bioinformatics Report — Porphyria Cutanea Tarda Type 2 (PCT2)
- **Course:** Introduction to Bioinformatics · UPC · 2026–2027
- **Group:** Porphyria Cutanea Tarda Type 2 (PCT2)
- **Authors:** Sara Charif Karkri el Abbassi and Laia Núñez Palma

## Description
This study provides a comparative bioinformatic and sequence alignment analysis of uroporphyrinogen decarboxylase (UROD), together with the interpretation of a 3D structural comparison provided by the course, to elucidate the molecular pathomechanism of porphyria cutanea tarda type 2 (PCT2). By evaluating the human wild-type and disease-associated variant (c.779T>C, p.Ile260Thr) alongside evolutionary orthologs (_Pan troglodytes_ and _Bacillus subtilis_), we propose that pathogenicity may be driven by local physicochemical disruption close to the active site rather than large-scale global structural distortion.
